## 背景

氧气瓶属于承压特种设备,在车间、施工现场通常成组存放于推车或瓶架中。碰撞、支架失效、违规斜靠、地面不平或积水结冰等情况都可能使其倾倒。瓶体倒伏后不仅会磕碰损伤瓶阀与减压器,一旦瓶阀断裂,高压气体高速喷出会让瓶体失去控制甚至成为"飞弹";而氧气本身是强助燃剂,泄漏后遇明火、油脂极易引发火灾乃至爆炸事故。因此,"瓶子是否倒伏"是现场最直接、也是最值得优先发现的安全征兆。

现场虽已部署固定摄像头用于区域监控,但目前仍依赖人工盯屏或定期巡检。氧气瓶区往往只占画面一角,倒伏通常在数秒内发生,人工很难长时间保持关注,夜间及多路视频并发时漏检风险更高,事后回溯也缺少结构化的告警记录。项目需要在此基础上增加一套自动、实时、可留存证据的倒伏检测能力。

## 技术方案

倒伏判定的本质,是比较**瓶身三维轴向**与**重力方向**之间的夹角:夹角超过阈值即为倒伏。因此方案的执行顺序是——先确定重力方向,再确定氧气瓶的朝向,最后比较两者夹角给出判定。

### 确定重力方向

现场为固定机位,相机安装姿态在运行期不变,重力方向在相机坐标系中是一个常量,因此只需标定一次即可全程复用。

具体做法:用单目几何模型(MoGe)将标定帧恢复为逐像素三维点云(相机坐标系,x 右、y 下、z 前);取画面下部约 45% 区域的有效点,RANSAC 拟合地面平面(随机三点定面、迭代 300 次,内点距离阈值取中位深度的 2%),再以全部内点做 SVD 最小二乘精化;平面法向取指向相机的一侧(即"上"),即为重力方向。

以地面法向作为重力有两个好处:不依赖任何重力估计网络,且与瓶身轴向来自同一份点云,不存在跨模型标定一致性问题。若画面下部看不到足够地面(RANSAC 内点率低于 35%),则降级为二维重力场(ParamNet)逐像素估计"上"方向,并回退到二维判据。

### 确定氧气瓶朝向

1. **检测**:YOLO 检出画面中的氧气瓶(`oxygen_tank`,conf ≥ 0.35),得到检测框;
2. **分割**:以检测框为 prompt 交给 SAM3,输出贴身的瓶身 mask,滤除框内背景(缺少这一步,点云 PCA 会被背景点拉偏);
3. **PCA**:取 mask 内有效三维点(≥50 个),去质心后对协方差矩阵做特征分解,最大特征值对应的特征向量即瓶身在相机坐标系中的真实三维轴向。

### 夹角判定

设瓶身轴向为 a、重力单位向量为 g,夹角 θ = arccos(|a·g|),θ > 45°(可配)判为倒伏(TIPPED)。

三维夹角判据对俯拍角和倒伏方位都不敏感:大俯拍角下直立瓶的投影会变"矮胖",但三维轴向不受影响;瓶子顺着视线方向躺倒(径向躺倒)时,二维投影看起来"像站着",而三维夹角仍接近 90°,不会漏判。

同时输出可信度提示:点云协方差前两大特征值之比 λ = λ₁/λ₂。λ 过小说明点云过"团"(mask 泄漏到背景,或瓶子几乎正对镜头),此时判定结果仅供人工复核。
