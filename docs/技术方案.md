## 背景

氧气瓶属于承压特种设备,在车间、施工现场通常成组存放于推车或瓶架中。碰撞、支架失效、违规斜靠、地面不平或积水结冰等情况都可能使其倾倒。瓶体倒伏后不仅会磕碰损伤瓶阀与减压器,一旦瓶阀断裂,高压气体高速喷出会让瓶体失去控制甚至成为"飞弹";而氧气本身是强助燃剂,泄漏后遇明火、油脂极易引发火灾乃至爆炸事故。因此,"瓶子是否倒伏"是现场最直接、也是最值得优先发现的安全征兆。

现场虽已部署固定摄像头用于区域监控,但目前仍依赖人工盯屏或定期巡检。氧气瓶区往往只占画面一角,倒伏通常在数秒内发生,人工很难长时间保持关注,夜间及多路视频并发时漏检风险更高,事后回溯也缺少结构化的告警记录。项目需要在此基础上增加一套自动、实时、可留存证据的倒伏检测能力。

结合现场与部署条件,项目的主要约束如下:

| 项 | 实际情况 |
|---|---|
| 传感与机位 | 复用现有固定枪机,单目 RGB,不改动硬件;实测俯仰角约 -32°~-56°(大俯拍) |
| 检测对象 | 氧气瓶:细长圆柱,高径比约 6:1,成组存放于推车/瓶架,瓶间存在相互遮挡 |
| 判定要求 | 以"直立/倒伏"二分类为主,中间倾斜等不确定状态允许转人工复核;判决阈值可配置 |
| 算力与环境 | 现场本地 GPU(RTX 4060 8GB),全部模型离线运行,不依赖外网;Windows 主机,无 MSVC 编译链 |
| 输出与联动 | 输出倒伏事件及对应角度、置信度,供现有监控平台做告警联动与截图存证 |

从技术上看,"倒伏"并非简单的图像分类问题,而是瓶体轴向相对重力方向的三维姿态问题。单目图像是三维场景的透视投影,直接由二维形状判断会引入投影歧义:大俯拍角下直立瓶的投影变得"矮胖",基于检测框高宽比的判据趋于失效;基于二维重力场与投影轴向夹角的判据,对"顺着视线方向躺倒"(径向躺倒)的瓶子存在必然漏判。项目因此确立了以单目几何恢复逐像素三维点云、以地面法向作为真实重力方向的技术路线,并保留二维重力场方案作为画面无可见地面时的降级路径。具体方案、实验验证与部署安排见后续章节。
