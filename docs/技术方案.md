**版本**: v1.0(2026-10-10)
**状态**: 算法管线已验证,待现场部署
**代码**: `F:\project\paramnet_yolo`

## 1. 背景与目标

氧气瓶在存放/使用过程中可能因碰撞、支架失效等原因倾倒,存在安全风险。本方案基于**固定摄像头视频监控**,自动检测画面内氧气瓶是否处于倒伏状态,输出实时告警。

核心需求与约束:

| 项 | 约束 |
|---|---|
| 传感 | 单目 RGB 摄像头,固定机位,大俯拍(实测 pitch 约 -32°~-56°) |
| 精度 | 能区分直立与倒伏,容忍中间倾斜状态的人工复核 |
| 部署 | 本地 GPU(RTX 4060 8GB),全部模型离线运行,不依赖外网 |
| 对象 | 氧气瓶(细长圆柱,高径比约 6:1),成组存放于推车/瓶架 |

## 2. 核心挑战与技术路线

### 2.1 问题的几何本质

"倒伏"是瓶子**轴向相对重力方向的三维姿态**问题。单目图像是 3D 场景的透视投影,直接从 2D 图像判断 3D 姿态存在投影歧义。方案演进经历了三个阶段,每一步都由明确的失效模式驱动。

### 2.2 路线演进与盲区分析(设计依据)

**路线 A:bbox 高宽比(detect 模型,初版)**
倒伏的圆柱投影扁平(h/w < 1),直立瘦高(h/w > 2)。实现最简单,但:
- **大俯拍角失效**: 俯拍越接近头顶视角,直立瓶投影越"胖",高宽比向 1 靠近 → 误报。实测场景 pitch 达 -56°,该判据只能作过渡。

**路线 B:2D 轴向-重力夹角(seg/OBB 模型 + 2D 重力场)**
利用射影几何性质:3D 竖直线的投影必过**竖直灭点**;2D 重力场(如 ParamNet)逐像素给出的"上"方向也指向同一灭点。直立瓶轴向必与所在位置的重力向量共线,倒伏则偏离。对大俯拍角免疫。
- **致命盲区——径向躺倒**: 瓶子**顺着视线方向**躺在地面时,其轴向灭点是"正前方地平点",重力灭点是"天顶点",两点同在画面上方一条竖直线且都远离画面。定量分析(pitch=-55.9°, vfov=47.1°, 即焦距约 1240px@1080p):从瓶子像素看这两个灭点的方向夹角**仅约 4°**,任意俯仰角下均小于 15°,恒低于 45° 判决阈值——**必然漏判**。且图像中"瓶头朝上躺倒"与"站立"几乎不可区分,这是投影把深度信息丢掉所致,更换任何 2D 重力估计器都无法解决。

**路线 C(最终):单目 3D 点云 + 地面拟合**
引入单目几何模型恢复逐像素 3D 点后,歧义消除:
- 瓶身 3D 点做 PCA → **瓶子真实 3D 轴向**;
- 画面下部 3D 点 RANSAC 拟合地面平面 → **法向量即重力方向**(不再依赖任何重力估计网络);
- 两者夹角即瓶子相对重力的**真实 3D 倾角**,对任意倒伏方位免疫。
- 附带收益: 轴向与重力来自同一份点云,无跨模型标定一致性问题。

## 3. 系统架构

```
                    ┌──────────────┐
 视频流/图像 ──────▶│ YOLO 检测     │──▶ 氧气瓶框(含 conf)
                    └──────────────┘
                           │ 框
                           ▼
                    ┌──────────────┐
                    │ SAM3 分割     │──▶ 瓶身贴身 mask(滤除框内背景)
                    └──────────────┘
                           │ mask
                           ▼
┌──────────────┐   ┌──────────────────┐
│ MoGe 单目几何 │──▶│ 3D 判定           │
│ 逐像素点云    │   │ · mask 内点 PCA → 瓶轴向      │
└──────┬───────┘   │ · 画面下部点 RANSAC → 地面法向=重力 │
       │           │ · 夹角 > 45° → TIPPED         │
       │           └──────────────────┘
       │ 地面法向(校准一次复用)
       ▼
   重力缓存(固定机位)
```

**固定机位复用策略**(核心工程决策): 重力方向由相机安装姿态唯一决定,静态不变。启动时用前 10 帧校准一次,运行期复用;MoGe 点云按间隔刷新(`--moge-every`,默认 10 帧);相机被移动/变焦/切分辨率后需重新校准。单帧运行成本大头为 YOLO。

## 4. 模块设计

### 4.1 YOLO 检测

- 模型: 自训练 `yolov11m`(detect 任务,类别 `oxygen_tank`),权重 `models/yolo.pt`;
- 输出: 检测框 + 置信度(conf ≥ 0.35);
- 后续可平滑升级: 代码按模型输出自动切换判据,训练 **seg**(分割)或 **OBB**(旋转框)版本后无需改主循环。

### 4.2 SAM3 分割(Meta)

- 作用: 检测框内混有瓶后背景,直接做点云 PCA 会被背景拉偏;SAM3 以检测框为 box prompt 输出贴身 mask,是点云质量的关键保障;
- 接口: `Sam3Segmenter.mask_from_box(x1,y1,x2,y2) → (H,W) bool`;
- 权重: `E:\modelscope\hub\models\sam3\sam3.pt`(3.3G,本地);
- 已知问题与修复: 官方代码在 Windows 下有三处不兼容(详见 §7.2),已在本地代码副本修补。

### 4.3 MoGe 单目几何(Microsoft)

- 作用: 单张图 → 逐像素 3D 点云(相机坐标系,x 右/y 下/z 前);
- 版本: **MoGe-2-vitl**(`E:\modelscope\hub\models\moge-2-vitl\model.pt`,1.3G)。曾计划用 MoGe-3,其精细精化模块(SSR)硬依赖 triton kernel + MSVC 编译链,部署机无 MSVC,故降级;MoGe-2 对轴向/平面法向估计足够;
- 尺度说明: 倾角判断只需方向,PCA 轴向与平面法向对平移/整体缩放不变,无需 metric 尺度(这也是不引入相机高度标定的原因)。

### 4.4 地面平面拟合(重力来源)

- 输入: 画面下部 45% 区域的有效 3D 点;
- 算法: RANSAC(采样 3 点定面,迭代 300 次,内点距离阈 2%·中位深度)→ 内点上 SVD 最小二乘精化;
- 定向: 法向取指向相机一侧(n·质心 < 0),即"上";
- 质量门限: 内点率 < 35% 判为"画面无可见地面",拒绝输出;
- 实测: 车间场景内点率 72%。

### 4.5 倒伏判据

1. mask 内 3D 点(≥50 点)去质心,协方差矩阵特征分解,最大特征向量 = 瓶身轴向;
2. 与重力单位向量夹角 θ = arccos(|axis·g|);
3. **θ > 45° → 倒伏(TIPPED)**,阈值可配;
4. 置信度提示: 伸长比 λ = λ₁/λ₂(协方差前两大特征值之比)。λ < 3 说明点云过"团"(mask 泄漏或瓶子近正对镜头),结果仅供复核。

### 4.6 Fallback 层级

| 优先级 | 条件 | 判据 | 限制 |
|---|---|---|---|
| 1(主管线) | `--moge --sam3` | 3D 轴向-重力夹角 | 无 |
| 2 | `--moge` 无 SAM3 | 框内深度带过滤后同上 | 背景残留,精度降 |
| 3 | 无地面可拟合 | ParamNet 2D 重力场 + mask 轴向夹角 | 径向盲区 |
| 4 | 仅 detect 框 | bbox 高宽比 | 大俯拍 + 径向双盲区 |

代码按实际可用资产自动降级,`run_image.py`/`run_video.py` 统一入口。

### 5.1 已知边界

- **重度遮挡**: 被推车半掩的瓶只有部分瓶身可见,PCA 受可见点分布影响,夹角偏大(36°)。伸长比指标可提示此情况,建议这类目标转人工复核;
- **YOLO 误检**: 画面中弯管被检为氧气瓶。属检测模型问题,计划补充负样本/难例重训;
- **缺失用例**: "瓶头朝镜头方向躺"(径向)照片尚未采集,该场景是 3D 管线的核心卖点,部署前必须补拍验收。

## 6. 部署方案

### 6.1 相机安装建议(直接决定算法上限)

1. **俯角控制在 45° 以内**: 俯角过深时地面点云对拟合误差敏感,且直立瓶投影变矮不利于目检;
2. **视线方向尽量垂直于瓶排走向**: 避免瓶子倒伏方向与视线共线,虽然 3D 管线已免疫,但正横躺的投影质量最好;
3. **保证画面下部有足够地面**: 地面拟合的内点率门限(35%)要求下部 45% 区域大部分是地面;
4. **固定焦距枪机优先**: 变焦/自动对焦会破坏校准复用;球机需锁定焦距并在变焦后触发重校准。

### 6.2 运行策略

- 启动: 加载三模型(约 20s)→ 首帧地面拟合 → 缓存重力;
- 运行: 每帧 YOLO(+SAM3 分割);MoGe 点云按 `--moge-every` 刷新;重力长期复用;
- 失效检测: 拟合内点率突降 / 深度图均值突变 → 提示相机被移动,自动重校准(待实现,当前为人工重启);
- 告警联动: TIPPED 事件 + 夹角 + 置信度输出,对接现有监控平台(待接)。

## 7. 工程实现要点

### 7.1 环境

- uv 管理,Python 3.12,torch 2.5.1+cu124(本地 wheel 离线安装);
- MoGe 三个依赖包为 GitHub git 依赖,经 codeload zip 本地安装(`--no-deps`),**`uv sync` 会移除它们,需重跑安装命令**(README 有记录);

### 7.2 SAM3 Windows 兼容补丁(本地 `E:\code\sam3`)

| 问题 | 修复 |
|---|---|
| 使用已移除的 `pkg_resources` | 改 `importlib.resources` |
| 视频跟踪链 import triton(需 MSVC) | 相关 import 懒加载,图像推理路径不加载 |
| `edt.py` triton kernel 无回退 | 无 triton 时自动降级 `cv2.distanceTransform` |
| checkpoint 混 bf16 权重,fp32 直推报 dtype 错 | 推理包 `torch.autocast(bfloat16)`(与官方示例一致) |
